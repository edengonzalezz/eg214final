# Ion concentrations in Puerto Rico streams before and after Hurricane Hugo.



## Purpose
R code for the replication of Figure 3 of the paper by Schaefer et al. (2000), which graphs the concentration of five different ions in different streams in Puerto Rico. The graph places year on the x-axis (1988-1994) facets by ion (potassium, nitrate, magnesium, calcium, and amonium) and plots the 9-week moving average concentration by four stream (Puente Roto Mameyes, Bisley Quebrada 1, Bisley Quebrada 2, Bisley Quebrada 3).
